# VESPER R — playable showcase

[Скачать сборки / Download builds](https://github.com/TSAR-it/vesper-r-builds/releases/latest)

Управляемый шоукейс заднеприводного суперкара. **Alder Valley** — открытая карта с шоссе, городом, перевалом и полигоном подвески. **Test Track** — отдельная трасса для коротких заездов. Есть вид из салона, режимы Comfort, Sport и Track, управление с клавиатуры, геймпада и калибруемого руля.

Доступные сборки предназначены для **Linux x86-64**. Распакуйте архив целиком и запустите `./VesperR.x86_64`. Справка по управлению открывается по **F10** или удержанием **Y** на геймпаде.

**В планах** — расширенная поддержка аэродинамики с прижимной силой и балансом по осям.

---

A playable rear-wheel-drive supercar showcase. **Alder Valley** is the open road map. **Test Track** is the smaller circuit. Both feature a cockpit view, driving profiles, and keyboard, gamepad and calibrated wheel input.

The builds target **Linux x86-64**. Extract the complete archive and run `./VesperR.x86_64`. Press **F10** or hold **Y** on a gamepad to open the controls guide.

**Roadmap** — expanded aerodynamics with downforce and front/rear aero balance.
